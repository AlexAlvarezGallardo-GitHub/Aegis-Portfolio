Aegis evolves continuously. This page tracks the platform's trajectory.

## Completed

- Identity Service — full hexagonal stack, 100% domain test coverage
- BFF Service — session security, JWT proxy, CSRF protection
- Wallet Service — digital wallets, idempotent ledger operations
- Fraud Service — rule-based real-time risk assessment
- Audit Service — immutable audit trail for platform events
- Transactional outbox on Kafka
- CI/CD with four parallel quality gates
- GitOps foundation with Argo CD
- Helm charts and environment overlays
- Observability stack — OpenTelemetry, Tempo, Prometheus, Loki, Grafana
- Supply-chain security — Trivy, CodeQL, Cosign, Syft, Dependabot

## In progress

- Payments track — transfers, merchant payments and refunds (UC-005–UC-007, [epic #246](https://github.com/AlexAlvarezGallardo-GitHub/Aegis/issues/246))
- Reporting projections — analytics, dashboards and exports

## Planned

- Notification Service — email, SMS and push with delivery tracking
- API Gateway with rate limiting and circuit breakers
- Argo Rollouts — blue/green and canary deployments
- KEDA autoscaling
- Policy as Code — OPA Gatekeeper

## Future vision

- External Secrets / HashiCorp Vault
- DORA metrics and ephemeral environments
- AI-native agent orchestration at runtime

## Principles that never change

- Infrastructure as Code.
- GitOps as the deployment model.
- Immutable deployments.
- Automated CI/CD.
- Secure software supply chain.
- Full observability.
- Everything version controlled.
